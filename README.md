Bridget To-Do List

A modern, responsive, and interactive To-Do List and Productivity Dashboard designed to help users organize daily tasks, project deadlines, notes, and productivity progress in one place.

🌐 Live Demo

Live Website:
https://bridget-pais.github.io/bridget-todo-list/

✨ Features

📊 Dashboard

- Overview of current tasks and productivity
- Task progress tracking
- Quick task creation
- Project and submission deadline management
- Productivity statistics

✅ Task Management

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Set task priority
- Set task status
- Track pending, completed, and delayed tasks

📅 Upcoming Tasks & Calendar

- Interactive monthly calendar
- Previous and next month navigation
- Current date highlighting
- Scheduled project/submission deadlines
- Date-based task filtering
- Upcoming submission list
- Date and time based deadline tracking

📝 Personal Journal

- Write and save personal diary entries
- Character counter
- Useful for recording:
  - College work
  - Projects
  - Meetings
  - Achievements
  - Ideas
  - Completed tasks

📈 Analytics

- Task completion percentage
- Productivity overview
- Task statistics
- Weekly performance tracking
- Visual progress representation

🔔 Notifications

- Notification panel
- Task and deadline related updates
- Empty notification state

💾 Local Storage

The application uses browser LocalStorage to store user data such as:

- Tasks
- Task status
- Deadlines
- Journal entries
- User preferences

This allows the application to retain data even after refreshing the page.

📱 Responsive Design

The interface is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices

🛠️ Technologies Used

- HTML5 — Structure and semantic markup
- CSS3 — Styling, layout, animations, and responsive design
- JavaScript — Application logic and interactivity
- Font Awesome — Icons
- LocalStorage API — Client-side data persistence

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/bridget-pais/bridget-todo-list.git

2. Open the Project

Navigate into the project folder:

cd bridget-todo-list

3. Run the Website

Open "index.html" in a web browser.

You can also use Live Server in Visual Studio Code for a better development experience.

🎯 Purpose of the Project

The purpose of this project is to create a centralized productivity platform where users can manage their tasks, project deadlines, daily activities, and productivity progress through a clean and user-friendly interface.

💡 Key Highlights

- Clean and modern dashboard
- Interactive calendar
- Task management system
- Project deadline tracking
- Task status and priority management
- Personal journal
- Analytics and progress tracking
- Responsive user interface
- Browser-based data storage
- No backend or database required
