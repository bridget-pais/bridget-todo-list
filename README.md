Bridget To-Do List

A modern and responsive To-Do List web application designed to help users organize tasks, track deadlines, maintain daily journal entries, and monitor their productivity.

Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Set task status as Pending, In Progress, Completed, or Delayed
- Task priority management
- Search and filter tasks
- Project/submission deadline management
- Calendar-based upcoming task view
- Date and time based submission tracking
- Today's Task personal diary/journal section
- Character limit for task and journal entries
- Task completion progress tracking
- Analytics and productivity overview
- Notifications panel
- Appearance/brightness settings
- Responsive design for different screen sizes
- Data stored using browser Local Storage

Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Browser Local Storage

How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in a browser.

For the best development experience, the project can be run using the Live Server extension in Visual Studio Code.

How It Works

The application uses JavaScript to manage tasks, deadlines, calendar data, journal entries, filters, notifications, and productivity information.

User data is stored in the browser's Local Storage, allowing tasks and other information to remain available when the page is reopened in the same browser.

Task Management

Users can create tasks and manage them using different statuses and priorities. Tasks can be edited, completed, searched, filtered, or deleted according to the user's requirements.

Upcoming Tasks

The Upcoming Tasks section provides a calendar interface where users can navigate between months and view scheduled project or submission deadlines.

Tasks can be displayed according to their scheduled date and time.

Today's Task

The Today's Task section works like a personal daily journal. Users can select a date and time and write about their activities, completed work, ideas, achievements, meetings, or other important events.

Analytics

The Analytics section provides an overview of task completion and productivity, helping users understand their progress.
